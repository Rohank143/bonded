# Third-party prompts

The adapters in this folder quote two system prompts word for word, so the Arena rates each framework's template as published:

- `AGENTKIT_TEMPLATE_PROMPT` is from Coinbase AgentKit, `typescript/examples/langchain-cdp-chatbot/chatbot.ts` (https://github.com/coinbase/agentkit). Apache License 2.0, Copyright 2024 Coinbase.
- `SOLANA_AGENT_KIT_TEMPLATE_PROMPT` is from Solana Agent Kit, `examples/misc/agent-kit-langgraph/src/index.ts` (https://github.com/sendaifun/solana-agent-kit). Apache License 2.0.

Both are used unmodified under the Apache License 2.0 (https://www.apache.org/licenses/LICENSE-2.0).

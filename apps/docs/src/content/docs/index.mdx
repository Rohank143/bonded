## The bar for AI agents

There is no common way yet to tell a hardened agent from a gullible one. Bonded gives every agent it rates the same attacks and the same 0 to 100 Bonded Score, signed and readable on Robinhood Chain, Arbitrum, Ethereum and Solana. A platform, vault or depositor can require a minimum score, and an agent builder has a number to measure up to. We set it first, in the open: the attack library, the scoring method and its assumptions are published next to the numbers.

## How it works

<CardGrid>
  <Card title="1. Mandate Vault" icon="approve-check">
    An agent trades from a vault that knows its rules: which tokens, which contracts, where funds
    may go, how much per trade and per day. A breach is blocked or recorded on chain.
  </Card>
  <Card title="2. The Arena" icon="warning">
    AI attacker scenarios are planted in the agent's world inside a sandbox: the main library's 10
    classes, judged by the vault's breach log, plus false market data (S1) and, for agents with
    memory Bonded can reset, poisoned memory, each judged against a clean run of the same world.
  </Card>
  <Card title="3. Bonded Score" icon="star">
    The manipulation rate on the agent's worst row gives the Bonded Score, a security grade from 0
    to 100. Breach losses give a separate insurance score and the premium. Signed by the attester
    and readable on Robinhood Chain, Arbitrum, Ethereum and Solana. The same scale for every agent,
    so it can serve as the standard.
  </Card>
  <Card title="4. Bond and cover" icon="open-book">
    The operator's bond pays first. Underwriters fund a pool that pays the rest. Depositors buy
    cover priced from the insurance score.
  </Card>
  <Card title="5. Automatic claims" icon="rocket">
    When the vault records a breach, the keeper files the claim within seconds. The contract slashes
    the bond, then the pool pays.
  </Card>
  <Card title="Sentinel" icon="setting">
    An optional real-time guard that flags manipulated actions before they reach the vault. It is
    advisory: payouts never depend on it.
  </Card>
</CardGrid>

Payouts and pass or fail are decided by deterministic logic in the vault and cover contracts,
never by an AI.

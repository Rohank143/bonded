drawn single-colour (as a mask in the text colour), so only their shape matters.

The licence covers the files. The marks themselves are trademarks of their owners, shown only to
say which framework an option is for.

Coinbase AgentKit has no mark here on purpose: the sources used only have the Coinbase wordmark, which is unreadable at icon size, and AgentKit's own asset is not a plain SVG.
